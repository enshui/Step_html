# Step_html · 小米运动步数展示页

小米运动（Zepp Life）刷步数项目的每日步数存档展示页，通过 GitHub Pages 纯静态托管。

**访问地址**：https://enshui.github.io/Step_html/

## 这是什么

一个单文件自包含 HTML 页面（`index.html`），数据直接内嵌在页面里，双击也能打开。页面提供：

- **日历选择**：点单个日期看当天，拖选/点两个日期看区间
- **账号筛选**：按账号过滤
- **单日视图**：当天各账号步数榜单
- **区间视图**：每日明细表

## 数据来源与更新

| 项目 | 说明 |
|---|---|
| 数据来源 | 私有仓库的 GitHub Actions 每日自动刷步数并归档 |
| 更新频率 | 每天北京时间 5:00 ~ 9:00 每小时一轮，每轮跑完自动更新本页 |
| 历史数据 | 从 2026-08-07 起持续累积，每天每人一条「最后一次步数」 |
| 更新方式 | 由 CI 自动 commit 到本仓库 `index.html`，**请勿手动修改** |

## 隐私说明

- 本页所有账号名均已脱敏：手机号保留前 3 后 4 位（如 `185****2459`），邮箱保留前 4 位以上、中间用 `*` 遮盖（如 `dash*****g@qq.ccc`、`zhin*@dhl.com`）
- 页面中只包含「日期 + 脱敏账号 + 步数」，无任何密码、token 或其他凭证
- 完整数据与登录凭证仅保存在私有仓库中，不对外公开

## 技术说明

- 纯静态：无后端、无接口请求，所有数据内嵌在 `index.html` 中
- 样式与脚本全部内联，零外部依赖，离线可用
- GitHub Pages 从 `main` 分支根目录发布
